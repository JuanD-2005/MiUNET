Glosario de Términos

Conceptos clave del proyecto y del área de Sistemas de Información.

Dato

Un hecho bruto o valor elemental que por sí solo no tiene significado completo. Los datos pueden ser números, palabras, fechas o símbolos. Ej.: "25", "Juan" o "01/09/2025".

Información

Conjunto de datos procesados, organizados o interpretados para generar significado y utilidad. Permite tomar decisiones y comprender fenómenos. Ej.: "Juan tiene 25 años".

Sistema

Conjunto de elementos interrelacionados que trabajan juntos para alcanzar un objetivo común. Tienen entradas (inputs), procesos y salidas (outputs), e incluyen personas, máquinas y procedimientos.

Procesamiento de Datos

Transformación de datos en información mediante recopilación, clasificación, almacenamiento, cálculo y análisis. Ej.: sumar ventas diarias para obtener un total mensual.

Sistemas de Información (SI)

Conjunto organizado de componentes — personas, hardware, software, datos y procedimientos — que recolecta, procesa, almacena y distribuye información para apoyar la toma de decisiones en una organización.

Chatbot

Sistema de inteligencia artificial que simula conversación humana para resolver consultas de forma automatizada, disponible 24/7 sin intervención manual constante.

Firebase

Plataforma de Google que ofrece servicios en la nube: autenticación, base de datos NoSQL (Firestore), almacenamiento, notificaciones push y hosting para apps móviles y web.

Aplicación Nativa

Aplicación desarrollada específicamente para un sistema operativo móvil (iOS o Android) usando el lenguaje oficial de la plataforma, garantizando rendimiento óptimo y acceso completo al hardware.

Roles de Usuario

Sistema de permisos que define las acciones disponibles para distintos tipos de usuarios. En MiUNET: Estudiante Profesor Administrador, cada uno con accesos diferenciados.
